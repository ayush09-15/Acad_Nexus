# CampusMind Classroom

An AI-powered classroom platform.

## Overview

CampusMind Classroom allows professors to create classrooms and upload course PDFs. Students can join classrooms using secure join keys, ask questions about uploaded study materials, and create personal study notes from AI-generated answers.

## Features

- Student and professor registration
- Institutional identity verification
- Classroom creation and secure join keys
- PDF-based AI chatbot with page citations
- Personal study notes
- Role-based access control

## Technology Stack

- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **AI Service:** Python, FastAPI
- **Vector Database:** Pinecone

## Project Status

Under development.

## Security

Environment variables, API keys, credentials, and private uploaded documents must not be committed to Git.
